# 쉼표,

> 잠깐 쉬어가도 괜찮아

학교 해커톤 **3번 주제 - 존중과 배려로 함께 안심하는 학교** 출품작입니다.

## 왜 만들었냐면

처음 회의할 때 각자 학교에서 봤던 일들을 얘기했는데, 다들 비슷한 말을 했어요.

"힘든 애들은 분명히 있는데, 걔네가 먼저 말을 안 한다."

신고하는 곳은 이미 있어요. 근데 '신고'라는 말부터 부담스럽고, 이름이 알려질까 봐,
아니면 "이 정도로 신고해도 되나?" 싶어서 그냥 참는 경우가 더 많았어요.
그리고 가해하는 쪽도 단톡방에서 생각 없이 던진 말이 문제가 되는 경우가 진짜 많고요.

그래서 **신고 전 단계**를 만들어보자고 했습니다.
매일 기분 버튼 하나 누르는 것, 말 보내기 전에 한 번 더 보는 것,
"그냥 들어주세요" 정도로 가볍게 도움을 요청하는 것부터요.

## 디자인

같은 동아리에서 만든 [ai-booth](https://github.com/ghclub-alt/ai-booth)에서 모눈 종이 배경, 테두리, 꾹 눌리는 버튼 느낌만 빌려왔어요.
색(초록·코랄)이랑 글꼴(Gowun Batang 제목 + IBM Plex Sans KR 본문)은 쉼표에 맞게 따로 정했습니다.

## 학생 화면과 선생님 화면은 주소가 달라요

| | 포트 | 누가 |
| --- | --- | --- |
| 학생 화면 | 3000 | 학생들한테 QR로 나눠줌 |
| 선생님 화면 | 3001 | 선생님만 (PIN 필요) |

처음엔 `/teacher.html` 이렇게 같은 주소 밑에 뒀는데, 그러면 학생이 주소 끝만 바꿔서 들어가 볼 수 있잖아요.
그래서 아예 서버를 두 개로 나눴어요. PIN이 1234 그대로면 학생 주소로는 선생님 화면이 아예 없어서 404가 떠요.

> 예외: ngrok 무료 계정은 고정 주소가 하나뿐이라, **PIN을 바꾸면** 학생 주소 밑 `/teacher/`에도 선생님 화면이 열려요.
> 학생이 주소를 알아도 PIN 없으면 못 들어가고, PIN은 10분에 5번 틀리면 막혀요.

## 기능

### 학생
- **오늘 마음 날씨** - 얼굴 버튼 하나로 기분 기록. 이름 없이 반만 저장돼요.
  일주일에 3번 넘게 힘들다고 하면 "얘기하러 가기"를 살짝 띄워줘요.
- **말 점검** - 단톡방에 보내기 전에 넣어보면 위험도 바늘이랑 같이 단톡방 화면처럼 보여줘요.
  - 상처 주는 말은 빨갛게 표시하고, 바꿔 말할 표현을 알려줘요
  - "바꾼 말로 다시 써보기" 누르면 자동으로 바꿔줌
  - 심한 말이면 **"잠깐! 보내기 전에"** 경고창이 떠요
  - ChatGPT 키 없으면 폰에서만 확인하고 서버로 안 보내요
  - **ChatGPT 키 있으면** AI가 같이 봐줘요: 상처 줄 수 있는 표현 표시, 받는 친구가 어떻게 느낄지, **바꿔 쓴 문장** + "이걸로 바꾸기"
    (욕 없이 따돌리는 말도 잡고, "죽어라 공부" 같은 건 괜찮다고 내려줌. 넣은 말은 저장 안 함)
- **도움 요청** - 1, 2, 3 단계로 천천히
  - 그냥 들어주세요 / 어떻게 하면 좋을지 알려주세요 / 선생님이 직접 도와주세요
  - 세 번째를 골랐을 때만 이름 칸이 나와요 (그것도 선택)
  - 쓰다가 "때린다", "죽고 싶다" 같은 말이 나오면 **바로 112 / 117 / 109 버튼이 떠요**
  - 보내면 접수번호 티켓이 나오고, 그걸로 선생님 답장을 확인해요
  - **쓰던 글은 자동 임시 저장**돼서 새로고침하거나 실수로 나가도 안 날아가요
  - **내가 보낸 이야기**는 새로고침해도 계속 남아 있고, 선생님 답장이 오면 홈에 "답장이 왔어"가 떠요
  - **선생님이랑 계속 대화**할 수 있어요. 이야기를 펼치면 채팅처럼 주고받기 (쓰던 답장도 임시 저장)
  - **새로고침 안 해도** 선생님 답장이 바로 떠요 (서버가 바로 알려주는 SSE 방식, 안 되면 15초마다 확인)
  - 답장 칸에서 **Enter = 보내기, Shift+Enter = 줄바꿈** (한글 마지막 글자 조합 중에 Enter 눌러도 줄바꿈 안 되고 보내져요)
  - 대화는 학생이 못 지워요. 지우는 건 선생님만
  - **보내기 전에 검수**: 도움 요청이랑 대화 답장 둘 다, 보내기 누르면 AI(키 없으면 단어 목록)가 먼저 봐요
  - **처음 적는 사연(상황 설명)은 욕이 섞여도 경고 안 함**: 있었던 일 털어놓다 보면 욕 나올 수 있으니까. 선생님한테 욕한 것만 경고
  - **대화에서 직접 쓴 욕은 바로 경고**: 보내기 전에 "이대로 보내면 바로 경고가 1번 쌓여" 창이 뜨고, 그래도 보내면 자동 경고 1번. 3번이면 대화 닫힘
  - **들은 말 옮긴 건 경고 안 함**: "걔가 저한테 OO이라고 했어요" 처럼 적으면 괜찮아요 (괴롭힘 당한 애가 경고 받으면 안 되니까). ChatGPT 켜져 있으면 대화 중에 있었던 일 설명하다 나온 욕도 경고 안 함
  - "죽어라 공부했어", "웃겨 죽어" 같은 말버릇은 욕으로 안 봐요
  - **2026년 유행어 속 욕/비하도 잡아요**: `존맛` `존잘` `두존크`(존X 들어감), `샤갈`(욕 대신 쓰는 감탄사), `급식충` `틀딱`, 교실까지 퍼졌다고 뉴스 나온 혐오 밈(`운지` `홍어` `탱크데이` 등)
    - `시1발` `ㅅ.ㅂ`처럼 숫자나 기호 끼운 것도 잡아요
    - 시바견, 피아노 운지법, 홍어회, 한남동, 화가 샤갈은 안 걸려요
  - 위험한 말(자해, 폭행 등)이 있으면 보낸 뒤에 112 / 117 / 109 연락처 창이 떠요
- **봤을 때** - 눈앞에서 봤을 때, 단톡방에서 봤을 때, 내가 당할 때, 내가 했을 때

### 선생님
- **알림** - 급한 순서대로 위에 떠요. 색이랑 글자(긴급/주의/참고) 둘 다 붙여놨어요
  - 긴급: 도움 요청에 위험한 말이 들어 있을 때
  - 주의: "직접 도와주세요"인데 12시간 넘게 답장 안 했을 때
  - 주의: 3일 연속 힘들다고 한 학생이 있을 때 (몇 명인지만, 누군지는 안 보여줌)
  - 참고: 오늘 갑자기 힘들다는 응답이 늘었을 때 / 이번 주 30% 넘을 때
  - 참고: 답장 안 한 메시지에 욕이 들어 있을 때 (옮겨 적은 건지 장난인지 확인해 달라고)
- **마음 날씨** - 요일별 쌓은 막대 그래프(마우스 올리면 자세히), 이번 주 비율표
- **도움 요청** - 위험 신호 있는 건 맨 위로. 위험한 단어는 빨갛게, 욕은 노랗게 표시돼요.
  학생이랑 주고받은 대화가 다 보이고, 학생이 다시 보내면 **새 메시지** 표시가 붙어요. 새로고침 안 해도 바로 떠요.
  빠른 답장 버튼으로 바로 답장할 수 있어요.
- **Enter로 답장**, **삭제** 버튼으로 대화 완전히 지우기 (학생 화면에서도 바로 없어짐, 되돌리기 안 됨. 삭제는 선생님만)
- **경고 주기** - 장난이나 욕설 메시지면 학생한테 경고를 보낼 수 있어요 (직접 쓰거나 기본 문구).
  **경고 3번이면 그 대화는 닫혀서** 학생이 더 못 보내요. 잘못 닫았으면 "다시 열기"
- 30초마다 알아서 새로고침, 새 요청 오면 알려줘요

## 앱으로 설치하기 (PWA)

학생 화면, 선생님 화면 둘 다 폰 홈 화면에 앱처럼 설치할 수 있어요. 앱스토어 안 거쳐도 됨.

- **안드로이드 (크롬)**: 학생 화면 홈에 "쉼표를 앱으로 설치하기" 카드가 뜨면 **설치** 누르기.
  선생님 화면은 왼쪽 아래 **앱으로 설치** 버튼
- **아이폰 (사파리)**: 아래 공유 버튼(□↑) → **홈 화면에 추가**
- 설치하면 주소창 없이 열리고, 학생은 "쉼표", 선생님은 "쉼표 선생님"으로 따로 깔려요
- 인터넷이 끊겨도 화면은 뜨고 위에 "인터넷이 끊겼어" 줄이 나와요. 쓰던 글은 폰에 남아 있어서 연결되면 그대로 보내면 됨
- 기분 기록, 도움 요청 같은 건 저장 안 하고 항상 서버로 보내요 (예전 답장이 보이면 헷갈리니까)

> PWA는 **https 주소**에서만 설치돼요. codespace 주소랑 `npm run share` 주소는 둘 다 https라서 괜찮고,
> 내 컴퓨터에서는 `localhost`로 열면 됩니다. `http://192.168...` 같은 주소로는 설치 버튼이 안 떠요.
>
> 화면 파일 고쳤는데 폰에서 예전 게 보이면 `public/shared/sw.js`의 `VERSION`을 올려주세요.

## 실행 방법 (GitHub Codespaces)

1. 이 레포에서 `Code` → `Codespaces` → `Create codespace on ...` (브랜치 이름)
2. 처음 열 때 알아서 `npm install`이랑 cloudflared 설치가 돼요 (1~2분 걸림)
3. 터미널에서

   ```bash
   npm start
   ```

그러면 학생 포트(3000)를 **공개(Public)** 로 바꾸고, **로그인 안 한 사람처럼 직접 들어가 봐서** 진짜 열리는지 확인해요.

```
학생 주소 확인 완료! 깃헙 로그인 없이 들어가져요.

=== 학생 화면 고정 주소 (codespace 안 지우면 안 바뀜) ===
(QR 코드)
 https://내codespace이름-3000.app.github.dev
```

이 주소는 **codespace를 지우지 않는 한 계속 똑같아요.** QR 한 번 뽑아두면 대회 내내 써도 됨.

### "아직 깃헙 로그인해야 들어가져요"가 나오면

학교/동아리 **조직(Organization) 설정이 공개 포트를 막고 있으면** 이렇게 돼요. 그럼 먼저 한 번만 직접 해보고:

아래 **포트(Ports)** 탭 → `3000` 오른쪽 클릭 → **Port Visibility** → **Public**

Public이 안 눌리거나 눌러도 로그인 화면이 뜨면 **ngrok**으로 열어요 👇

### ngrok으로 열기 (codespace 공개가 막혀 있을 때)

한 번만 설정해두면 `npm start` 할 때 ngrok도 같이 켜져요.

1. [ngrok](https://dashboard.ngrok.com) 가입 (구글 로그인 됨)
2. **Your Authtoken** 메뉴에서 토큰 복사
3. **Domains** 메뉴에서 무료 도메인 하나 받기 (`○○○.ngrok-free.app`) → 이거 있으면 **주소가 안 바뀜**
4. `.env` 파일에 넣기

   ```
   NGROK_AUTHTOKEN=복사한토큰
   NGROK_DOMAIN=○○○.ngrok-free.app
   ```

5. `npm start`

```
ngrok 켜짐! 깃헙 로그인 없이 누구나 들어올 수 있어요.
=== 학생 화면 고정 주소 (ngrok 고정 도메인) ===
(QR 코드)
 https://○○○.ngrok-free.app
```

- 처음 들어가면 ngrok 안내 화면이 한 번 떠요 → **Visit Site** 누르면 됨
- `ngrok이 없어요` 나오면 `bash scripts/install-tunnel.sh` 한 번
- `이 ngrok 계정이 벌써 다른 데서 켜져 있어요` → 무료 계정은 한 군데서만 켜져요. 다른 터미널의 ngrok 끄기
- `이 주소에 선생님 화면이 떠요` → 예전에 켠 ngrok이 아직 같은 주소를 쓰는 거예요. 다른 터미널의 ngrok 끄고, [ngrok 대시보드](https://dashboard.ngrok.com) → Endpoints에 남아 있는 것도 끈 다음 `npm start` 다시
- 토큰은 `.env`에만! 깃헙에 올리면 안 돼요

### 선생님 화면은?

- **PIN이 1234 그대로면** 선생님 화면은 밖에서 안 열려요 (codespace 주인만 깃헙 로그인해서 들어감)
- `.env`에서 **`TEACHER_PIN`을 바꾸면** 선생님 화면이 **학생 주소 + `/teacher/`** 로 열려요. 학생 주소가 고정이면 이것도 고정
  - 예: 학생 `https://○○○.ngrok-free.app` → 선생님 `https://○○○.ngrok-free.app/teacher/`
  - 선생님 폰이나 심사위원 노트북에서도 로그인 없이 들어가짐 (PIN만)
  - 선생님 화면도 앱으로 설치돼요. 학생 앱이랑 따로 깔림
- ngrok 터널은 학생 거 하나만 열어요. 무료 계정은 도메인이 하나뿐이라 둘 다 열면 같은 주소에 겹쳐서 **선생님 화면만 뜨는** 일이 생겨서
- PIN을 10분에 5번 틀리면 잠깐 막혀요 (아무나 찍어서 못 들어오게)
- 밖에서 열기 싫으면 `.env`에 `TEACHER_PUBLIC=0`

### 대회 날 체크리스트

- [ ] **codespace 꺼지는 시간 늘리기**: 깃헙 → Settings → Codespaces → **Default idle timeout** → `240`분
      (기본 30분이라 가만히 두면 꺼져요. 꺼져 있으면 주소가 안 열림. 다시 켜면 같은 주소로 돌아와요)
- [ ] 발표하는 동안 codespace 탭 열어두기
- [ ] **깃헙 로그인 안 된 폰**으로 학생 주소 들어가지는지 미리 확인
      (처음 들어갈 때 깃헙 안내 화면이 한 번 뜨면 계속하기 누르면 됨)
- [ ] 선생님 PIN 바꾸기
- [ ] codespace 공개가 안 되면 ngrok 토큰이랑 고정 도메인 `.env`에 넣어두기
- [ ] 쓰던 codespace **지우지 않기** (지우면 주소 바뀜. 30일 넘게 안 쓰면 깃헙이 자동으로 지울 수 있어요)

### 예비: `npm run share` (cloudflare 임시 주소)

codespace 공개가 안 되거나, codespace가 아닌 데서 돌릴 때 쓰는 방법이에요.
**켤 때마다 주소가 바뀌어요.**

```bash
npm run share
```

학생/선생님 주소랑 학생 QR이 나오고, 깃헙 로그인 없이 들어올 수 있어요.

### `EADDRINUSE` / "포트 3000번을 벌써 다른 서버가 쓰고 있어요"

서버가 이미 다른 터미널에서 켜져 있다는 뜻이에요.

- 공개 주소가 필요하면 그냥 `npm run share` → 켜져 있는 서버 그대로 쓰고 주소만 만들어줌
- 새로 켜고 싶으면 켜져 있는 터미널에서 `Ctrl+C`로 끄고 다시 (터미널 창 휴지통 아이콘으로 닫아도 됨)

### cloudflare가 안 될 때

- `cloudflared가 없어요` → `bash scripts/install-tunnel.sh` 한 번 돌리기
- `cloudflare 서버에 연결이 안 돼요` → 학교 와이파이가 막는 경우가 있어요. 폰 핫스팟으로 해보거나 ngrok 쓰기
- ngrok: 위에 [ngrok으로 열기](#ngrok으로-열기-codespace-공개가-막혀-있을-때) 보고 `.env`에 토큰 넣고 `npm start`

### 내 컴퓨터에서 돌릴 때

Node.js 18 이상 깔려 있으면

```bash
npm install
npm start
```

학생은 http://localhost:3000, 선생님은 http://localhost:3001

### 설정

| 환경변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 학생 화면 포트 |
| `TEACHER_PORT` | 3001 | 선생님 화면 포트 |
| `TEACHER_PIN` | 1234 | 선생님 화면 비밀번호 |
| `TEACHER_PUBLIC` | (없음) | 선생님 주소 밖에서 열기. 없으면 PIN 바꿨을 때만, `1`이면 항상, `0`이면 안 엶 |
| `NGROK_AUTHTOKEN` | (없음) | 넣으면 `npm start` 할 때 ngrok도 켜짐 |
| `NGROK_DOMAIN` | (없음) | ngrok 무료 고정 도메인 (학생 주소 안 바뀌게) |
| `OPENAI_API_KEY` | (없음) | 넣으면 ChatGPT로 메시지 판단 |
| `OPENAI_MODEL` | gpt-4.1-mini | 쓸 모델 |

**시연 전에 PIN 꼭 바꾸기!**

```bash

```

## ChatGPT로 판단하기 (선택)

OpenAI API 키를 넣으면 학생 메시지를 ChatGPT가 같이 봐요. 안 넣어도 단어 목록으로 다 돌아가요.

| | 단어 목록 (기본) | ChatGPT |
| --- | --- | --- |
| "선생님 걔가 저한테 OO이라고 했어요" | `라고`, `했어` 있으면 넘어감 | 옮긴 말인지 문맥으로 판단 |
| "요즘 그냥 다 끝내고 싶어요" | 목록에 없으면 못 잡음 | 위험 신호로 **긴급** 알림 |
| "죽어라 공부했어요" | 욕으로 잘못 잡음 | 욕 아님 → 욕설 표시 뺌 |
| 장난 메시지 | 모름 | "장난 같은 메시지" 알림 |

선생님 화면에는 걸린 메시지 밑에 `AI · 이유`가 나와요. 최종 판단은 선생님이!

**말 점검**에서도 써요. 단어 목록으로 먼저 바로 보여주고, 이어서 AI가 표현 짚어주고 바꿔 쓴 문장까지 줘요.

### 키 넣는 법

**codespace 비밀값으로 넣기 (추천)** - 깃헙에 키가 절대 안 올라가요

1. 깃헙 → Settings → Codespaces → **Secrets** → `New secret`
2. 이름 `OPENAI_API_KEY`, 값에 키 붙여넣고, Repository access에서 이 레포 선택
3. codespace 화면에 "다시 시작하라"는 알림 뜨면 누르기 (안 뜨면 왼쪽 아래 `Codespaces` → `Rebuild Container`)

**또는 .env 파일로**

```bash
cp .env.example .env
# .env 열어서 OPENAI_API_KEY= 뒤에 키 붙여넣기
```

`.env`는 `.gitignore`에 있어서 커밋 안 돼요. 그래도 **키를 코드나 README에 직접 쓰지 마세요.** 깃헙에 올라가면 바로 털려요.

### 켜졌는지 확인

`npm start` 하면 키가 진짜 되는지 OpenAI에 한 번 물어보고 알려줘요.

```
ChatGPT → 키 확인 중... 키 sk-...a1b2 (codespace 비밀값)
ChatGPT → 켜짐! (gpt-4.1-mini) 말 점검이랑 메시지 판단에 써요
```

| 나오는 말 | 뜻 / 할 일 |
| --- | --- |
| `꺼짐 (OPENAI_API_KEY 없음)` | 키를 안 넣었거나, codespace 비밀값 넣고 codespace를 다시 안 켬 |
| `키가 틀렸어요 (401)` | 키 다시 복사해서 넣기 |
| `크레딧(돈)이 없어요` | OpenAI 결제(Billing) 확인 |
| `모델을 이 키로 못 써요` | `.env`의 `OPENAI_MODEL` 바꾸기 |
| `OpenAI에 연결이 안 돼요` | 인터넷 확인. 일단 켜두고 안 되면 단어 목록으로 |

키가 틀렸거나 돈이 없으면 그냥 단어 목록으로 돌아가요. 선생님 화면 왼쪽 위에서도 켜짐/꺼짐이 보여요.

키 어디서 읽었는지도 나와요: `.env 파일` / `codespace 비밀값` / `환경변수`

**키 유출 경고**: `.env`가 git에 올라가 있거나 코드에 `sk-...` 같은 게 있으면 `npm start` 할 때 `!!!` 경고가 떠요.
이미 깃헙에 올라갔으면 OpenAI에서 그 키를 지우고 새로 만드세요.

- 학생 이름은 안 보내고 **메시지 내용만** 보내요. 학생 화면에도 "AI가 같이 확인해" 안내가 떠요
- 8초 안에 답이 없거나 실패하면 그냥 단어 목록으로 판단해요 (그래서 키 잘못 넣어도 앱은 돌아감. 서버 로그에 `[AI] 실패` 찍힘)
- 말 점검은 한 사람이 1분에 20번까지만 (돈 나가니까)
- 메시지 하나에 1번 부르고, gpt-4.1-mini도 싼 편이라 해커톤 동안은 얼마 안 나와요. 그래도 OpenAI 대시보드에서 사용 한도 걸어두기

## 코드 최신으로 받기 (codespace 안 지우고)

codespace를 지우면 주소가 바뀌니까, 지우지 말고 코드만 새로 받으면 돼요.

```bash
npm run update
```

이게 알아서 해주는 거:
1. 지금 브랜치 최신 코드 받기 (`git pull`)
2. 새로 필요한 패키지 설치 (`npm install`)
3. 직접 고친 파일 있으면 잠깐 치워뒀다가 다시 넣기

그다음 **서버 껐다 켜기**: 서버 켜진 터미널에서 `Ctrl+C` → `npm start`

> 서버를 `npm run dev`로 켜두면 코드 바뀔 때 알아서 다시 켜져요.
> 학생/선생님 폰은 새로고침 한 번 (앱으로 설치했으면 껐다 켜기)

- 기분 기록, 도움 요청(`data/db.json`), API 키(`.env`)는 git에 없어서 업데이트해도 그대로예요
- 손으로 하고 싶으면 VS Code 왼쪽 **소스 제어(Source Control)** 아이콘 → `...` → **Pull**, 또는 터미널에서 `git pull`

## 시연 순서 (3분)

1. 선생님 화면에서 2학년 3반 고르고 왼쪽 아래 **시연용 데이터 넣기** → 알림, 그래프, 요청 목록 채워짐
2. 학생 화면(폰)에서 2학년 3반 선택 → "많이 힘들어" 누르기 → "얘기하러 가기" 뜨는 거 보여주기
3. 말 점검 → 예시 `@지민 닥쳐 관종아!!!` 누르기 → 경고창 → 결과 → "바꾼 말로 다시 써보기"
4. 도움 요청 → 단톡방·SNS → "사진 뿌린다고 협박해요" 쓰면 바로 연락처 뜨는 거 보여주기 → 직접 도와주세요 → 보내기 → 티켓
5. 선생님 화면 → 맨 위에 빨간 **긴급** 알림 → 보러 가기 → 빠른 답장으로 답장
6. 다시 학생 화면 → 내가 보낸 이야기에서 선생님 답장 확인 → 바로 답장 이어서 보내기
7. 선생님 화면 → 시연용 데이터에 있는 `존나 심심하다 선생님 병신` 장난 메시지 → **경고 주기** 3번 → 대화 닫힘
