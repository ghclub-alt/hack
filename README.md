# 쉼표,

> 잠깐 쉬어가도 괜찮아

학교 해커톤 **3번 주제 - 존중과 배려로 함께 안심하는 학교** 출품작입니다.

## 왜 만들었냐면

처음 회의할 때 각자 학교에서 봤던 일들을 얘기했는데, 다들 비슷한 말을 했어요.

"힘든 애들은 분명히 있는데, 걔네가 먼저 말을 안 한다."

신고하는 곳은 이미 있어요. 근데 '신고'라는 말부터 부담스럽고, 이름이 알려질까 봐,
아니면 "이 정도로 신고해도 되나?" 싶어서 그냥 참는 경우가 더 많았어요.
그리고 가해하는 쪽도 단톡방에서 생각 없이 던진 말이 문제가 되는 경우가 진짜 많고요.

그래서 **신고 전 단계**를 만들어보자고 했습니다.
매일 기분 버튼 하나 누르는 것, 말 보내기 전에 한 번 더 보는 것,
"그냥 들어주세요" 정도로 가볍게 도움을 요청하는 것부터요.

## 기능

### 학생
- **오늘 기분** - 버튼 하나로 기분을 남겨요. 이름 없이 반만 저장돼요.
  일주일에 3번 넘게 힘들다고 하면 "얘기하러 가기"를 살짝 띄워줘요.
- **말 점검** - 단톡방에 보내기 전에 넣어보면 상처 주는 말을 표시하고, 바꿔 말할 표현을 알려줘요.
  이건 일부러 서버로 안 보내요. 아직 보내지도 않은 말을 저장할 이유가 없어서요.
- **도움 요청** - 어떤 도움을 원하는지 3단계로 고를 수 있어요.
  - 그냥 들어주세요 / 어떻게 하면 좋을지 알려주세요 / 선생님이 직접 도와주세요
  - 세 번째를 골랐을 때만 이름 칸이 나와요 (그것도 선택)
  - 보내면 접수번호 4자리가 나오고, 그걸로 선생님 답장을 확인해요
- **봤을 때** - 친구가 괴롭힘 당하는 걸 봤을 때, 단톡방에서 봤을 때 할 수 있는 것들

### 선생님 (`/teacher.html`)
- **마음 날씨** - 우리 반 일주일 기분 통계. 누가 뭘 눌렀는지는 절대 안 보여요. 숫자만.
  힘들다는 비율이 30% 넘으면 알려줘요.
- **도움 요청 목록** - 답장 보내기, 마무리 처리. "직접 도와주세요"는 눈에 띄게 표시돼요.

## 실행 방법 (GitHub Codespaces)

1. 이 레포에서 `Code` → `Codespaces` → `Create codespace on ...` (브랜치 이름)
2. 처음 열 때 알아서 `npm install`이랑 터널 프로그램 설치가 돼요 (1~2분 걸림)
3. 터미널에서

   ```bash
   npm start
   ```

4. 오른쪽 아래 "포트 3000 열림" 알림 뜨면 눌러서 확인

### 다른 사람 폰으로 접속하기 (시연할 때)

터미널을 **하나 더** 열어서 (서버는 켜둔 상태로)

```bash
npm run tunnel
```

조금 기다리면 `https://어쩌고저쩌고.trycloudflare.com` 주소가 나와요. 그거 QR로 만들어서 심사위원분들 폰으로 찍게 하면 됩니다.
cloudflare는 가입 안 해도 돼서 이걸 기본으로 했어요.

ngrok 쓰고 싶으면 [ngrok 대시보드](https://dashboard.ngrok.com/get-started/your-authtoken)에서 토큰 받아서

```bash
NGROK_AUTHTOKEN=토큰 npm run tunnel:ngrok
```

> 터널 프로그램이 설치 안 돼 있다고 나오면 `bash scripts/install-tunnel.sh` 한 번 돌리기

### 내 컴퓨터에서 돌릴 때

Node.js 18 이상 깔려 있으면

```bash
npm install
npm start
```

### 설정

| 환경변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 서버 포트 |
| `TEACHER_PIN` | 1234 | 선생님 화면 비밀번호 |

**시연 전에 PIN 꼭 바꾸기!** 터널 열면 주소 아는 사람은 다 들어올 수 있어요.

```bash
TEACHER_PIN=0427 npm start
```

## 시연 순서 (3분)

1. 선생님 화면에서 2학년 3반 고르고 **시연용 데이터 넣기** → 마음 날씨, 요청 목록 채워짐
2. 학생 화면(폰)에서 2학년 3반 선택 → 기분 "많이 힘들어" 누르기 → "얘기하러 가기" 뜨는 거 보여주기
3. 말 점검에 `@민지 야 너 진짜 노답이다 ㅋㅋㅋ 꺼져!!!` 넣고 확인 → 빨간 경고 + 바꿔 말하기
4. 도움 요청 → 단톡방·SNS / 직접 도와주세요 → 접수번호 받기
5. 선생님 화면 새로고침 → 방금 요청 맨 위에 뜸 → 답장 보내기
6. 다시 학생 화면 → 접수번호 눌러서 답장 확인

## 폴더 구조

```
server.js            서버 (express)
public/
  index.html         학생 화면
  teacher.html       선생님 화면
  css/style.css
  js/data.js         기분 종류, 상처 주는 말 목록, 가이드 내용
  js/common.js       둘 다 쓰는 함수
  js/main.js         학생 화면 코드
  js/teacher.js      선생님 화면 코드
scripts/             터널 설치/실행 스크립트
data/db.json         저장 파일 (자동 생성, git에는 안 올라감)
```

## 아쉬운 점 / 나중에 하고 싶은 것

- DB 대신 json 파일에 저장해요. 시간이 없어서... 실제로 쓰려면 DB 붙여야 함
- 선생님 로그인이 PIN 하나라서 반별 선생님 계정이 따로 없음
- 말 점검이 단어 목록 방식이라 "죽어라 공부했다" 같은 것도 걸려요. 문맥 보는 건 다음에
- 학부모용 화면도 만들고 싶었는데 못 함 (선생님 연락 가능 시간 같은 거)
- 기분이 며칠 연속 안 좋은 학생한테 상담 선생님이 먼저 익명으로 말 걸 수 있게 하기
