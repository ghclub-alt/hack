# 쉼표,

> 잠깐 쉬어가도 괜찮아

학교 해커톤 **3번 주제 - 존중과 배려로 함께 안심하는 학교** 출품작입니다.

## 왜 만들었냐면

처음 회의할 때 각자 학교에서 봤던 일들을 얘기했는데, 다들 비슷한 말을 했어요.

"힘든 애들은 분명히 있는데, 걔네가 먼저 말을 안 한다."

신고하는 곳은 이미 있어요. 근데 '신고'라는 말부터 부담스럽고, 이름이 알려질까 봐,
아니면 "이 정도로 신고해도 되나?" 싶어서 그냥 참는 경우가 더 많았어요.
그리고 가해하는 쪽도 단톡방에서 생각 없이 던진 말이 문제가 되는 경우가 진짜 많고요.

그래서 **신고 전 단계**를 만들어보자고 했습니다.
매일 기분 버튼 하나 누르는 것, 말 보내기 전에 한 번 더 보는 것,
"그냥 들어주세요" 정도로 가볍게 도움을 요청하는 것부터요.

## 디자인

같은 동아리에서 만든 [ai-booth](https://github.com/ghclub-alt/ai-booth)에서 모눈 종이 배경, 테두리, 꾹 눌리는 버튼 느낌만 빌려왔어요.
색(초록·코랄)이랑 글꼴(Gowun Batang 제목 + IBM Plex Sans KR 본문)은 쉼표에 맞게 따로 정했습니다.

## 학생 화면과 선생님 화면은 주소가 달라요

| | 포트 | 누가 |
| --- | --- | --- |
| 학생 화면 | 3000 | 학생들한테 QR로 나눠줌 |
| 선생님 화면 | 3001 | 선생님만 (PIN 필요) |

처음엔 `/teacher.html` 이렇게 같은 주소 밑에 뒀는데, 그러면 학생이 주소 끝만 바꿔서 들어가 볼 수 있잖아요.
그래서 아예 서버를 두 개로 나눴어요. 학생 주소로는 선생님 API가 아예 없어서 404가 떠요.

## 기능

### 학생
- **오늘 마음 날씨** - 얼굴 버튼 하나로 기분 기록. 이름 없이 반만 저장돼요.
  일주일에 3번 넘게 힘들다고 하면 "얘기하러 가기"를 살짝 띄워줘요.
- **말 점검** - 단톡방에 보내기 전에 넣어보면 위험도 바늘이랑 같이 단톡방 화면처럼 보여줘요.
  - 상처 주는 말은 빨갛게 표시하고, 바꿔 말할 표현을 알려줘요
  - "바꾼 말로 다시 써보기" 누르면 자동으로 바꿔줌
  - 심한 말이면 **"잠깐! 보내기 전에"** 경고창이 떠요
  - 이건 일부러 서버로 안 보내요. 아직 보내지도 않은 말을 저장할 이유가 없어서요
- **도움 요청** - 1, 2, 3 단계로 천천히
  - 그냥 들어주세요 / 어떻게 하면 좋을지 알려주세요 / 선생님이 직접 도와주세요
  - 세 번째를 골랐을 때만 이름 칸이 나와요 (그것도 선택)
  - 쓰다가 "때린다", "죽고 싶다" 같은 말이 나오면 **바로 112 / 117 / 109 버튼이 떠요**
  - 보내면 접수번호 티켓이 나오고, 그걸로 선생님 답장을 확인해요
  - **쓰던 글은 자동 임시 저장**돼서 새로고침하거나 실수로 나가도 안 날아가요
  - **내가 보낸 이야기**는 새로고침해도 계속 남아 있고, 선생님 답장이 오면 홈에 "답장이 왔어"가 떠요
- **봤을 때** - 눈앞에서 봤을 때, 단톡방에서 봤을 때, 내가 당할 때, 내가 했을 때

### 선생님
- **알림** - 급한 순서대로 위에 떠요. 색이랑 글자(긴급/주의/참고) 둘 다 붙여놨어요
  - 긴급: 도움 요청에 위험한 말이 들어 있을 때
  - 주의: "직접 도와주세요"인데 12시간 넘게 답장 안 했을 때
  - 주의: 3일 연속 힘들다고 한 학생이 있을 때 (몇 명인지만, 누군지는 안 보여줌)
  - 참고: 오늘 갑자기 힘들다는 응답이 늘었을 때 / 이번 주 30% 넘을 때
- **마음 날씨** - 요일별 쌓은 막대 그래프(마우스 올리면 자세히), 이번 주 비율표
- **도움 요청** - 위험 신호 있는 건 맨 위로. 위험한 단어는 빨갛게 표시돼요.
  빠른 답장 버튼으로 바로 답장할 수 있어요.
- 30초마다 알아서 새로고침, 새 요청 오면 알려줘요

## 앱으로 설치하기 (PWA)

학생 화면, 선생님 화면 둘 다 폰 홈 화면에 앱처럼 설치할 수 있어요. 앱스토어 안 거쳐도 됨.

- **안드로이드 (크롬)**: 학생 화면 홈에 "쉼표를 앱으로 설치하기" 카드가 뜨면 **설치** 누르기.
  선생님 화면은 왼쪽 아래 **앱으로 설치** 버튼
- **아이폰 (사파리)**: 아래 공유 버튼(□↑) → **홈 화면에 추가**
- 설치하면 주소창 없이 열리고, 학생은 "쉼표", 선생님은 "쉼표 선생님"으로 따로 깔려요
- 인터넷이 끊겨도 화면은 뜨고 위에 "인터넷이 끊겼어" 줄이 나와요. 쓰던 글은 폰에 남아 있어서 연결되면 그대로 보내면 됨
- 기분 기록, 도움 요청 같은 건 저장 안 하고 항상 서버로 보내요 (예전 답장이 보이면 헷갈리니까)

> PWA는 **https 주소**에서만 설치돼요. `npm run share`로 나온 주소는 https라서 괜찮고,
> 내 컴퓨터에서는 `localhost`로 열면 됩니다. `http://192.168...` 같은 주소로는 설치 버튼이 안 떠요.
>
> 화면 파일 고쳤는데 폰에서 예전 게 보이면 `public/shared/sw.js`의 `VERSION`을 올려주세요.

## 실행 방법 (GitHub Codespaces)

1. 이 레포에서 `Code` → `Codespaces` → `Create codespace on ...` (브랜치 이름)
2. 처음 열 때 알아서 `npm install`이랑 cloudflared 설치가 돼요 (1~2분 걸림)
3. 터미널에서

   ```bash
   npm run share
   ```

10초쯤 기다리면 이렇게 나와요.

```
================================================
 학생 화면  (이 QR을 화면에 띄우거나 나눠주세요)
================================================
(QR 코드)
 https://어쩌고-저쩌고.trycloudflare.com

================================================
 선생님 화면  (선생님만! 학생한테 보여주지 말기)
================================================
 https://이런-저런.trycloudflare.com
```

**이 주소는 깃헙 계정 없이 아무나 들어올 수 있어요.** 학생 QR만 띄워주면 됩니다.
끄려면 `Ctrl+C`. 다시 켜면 주소가 바뀌어요.

### 왜 `npm start` 말고 `npm run share`?

`npm start`만 하면 `https://...app.github.dev` 주소가 나오는데, 이건 codespace 주인 깃헙 계정으로 로그인해야만 들어가져요.
학생들 폰으로는 못 들어옴. 그래서 cloudflare 터널로 공개 주소를 하나 더 만들어서 그걸 쓰는 거예요.
(혼자 화면 고치면서 볼 때는 `npm start`로 충분)

### cloudflare가 안 될 때

- `cloudflared가 없어요` → `bash scripts/install-tunnel.sh` 한 번 돌리기
- `cloudflare 서버에 연결이 안 돼요` → 학교 와이파이가 막는 경우가 있어요. 폰 핫스팟으로 해보거나 ngrok 쓰기
- ngrok: [ngrok 대시보드](https://dashboard.ngrok.com/get-started/your-authtoken)에서 토큰 받아서, `npm start` 켜둔 상태로 다른 터미널에서

  ```bash
  NGROK_AUTHTOKEN=토큰 npm run tunnel:ngrok
  ```

  (무료 계정에서 터널 두 개가 동시에 안 열리면 학생 화면 하나만이라도)
- codespace 포트를 공개로 바꾸는 방법도 있어요: 아래 `포트(Ports)` 탭 → 3000 오른쪽 클릭 → `Port Visibility` → `Public`
  (이렇게 하면 깃헙 로그인 없이 들어가짐. 선생님 3001은 그대로 두기)

### 내 컴퓨터에서 돌릴 때

Node.js 18 이상 깔려 있으면

```bash
npm install
npm start
```

학생은 http://localhost:3000, 선생님은 http://localhost:3001

### 설정

| 환경변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 학생 화면 포트 |
| `TEACHER_PORT` | 3001 | 선생님 화면 포트 |
| `TEACHER_PIN` | 1234 | 선생님 화면 비밀번호 |

**시연 전에 PIN 꼭 바꾸기!**

```bash
TEACHER_PIN=0427 npm run share
```

## 시연 순서 (3분)

1. 선생님 화면에서 2학년 3반 고르고 왼쪽 아래 **시연용 데이터 넣기** → 알림, 그래프, 요청 목록 채워짐
2. 학생 화면(폰)에서 2학년 3반 선택 → "많이 힘들어" 누르기 → "얘기하러 가기" 뜨는 거 보여주기
3. 말 점검 → 예시 `@지민 닥쳐 관종아!!!` 누르기 → 경고창 → 결과 → "바꾼 말로 다시 써보기"
4. 도움 요청 → 단톡방·SNS → "사진 뿌린다고 협박해요" 쓰면 바로 연락처 뜨는 거 보여주기 → 직접 도와주세요 → 보내기 → 티켓
5. 선생님 화면 → 맨 위에 빨간 **긴급** 알림 → 보러 가기 → 빠른 답장으로 답장
6. 다시 학생 화면 → 접수번호 눌러서 선생님 답장 확인

## 폴더 구조

```
server.js              서버 (학생 3000, 선생님 3001 따로 띄움)
db.js                  json 파일 저장
public/
  shared/              둘 다 쓰는 거
    data.js            기분 종류, 상처 주는 말, 위험 단어, 가이드 (서버도 이거 씀)
    common.js          공통 함수, 얼굴 그림
    icons.js           아이콘
    sw.js              서비스 워커 (앱 설치, 인터넷 끊겨도 화면 뜨게)
    base.css
  student/             학생 화면 (+ manifest, 아이콘)
  teacher/             선생님 화면 (+ manifest, 아이콘)
scripts/               터널 설치/실행 스크립트
data/db.json           저장 파일 (자동 생성, git에는 안 올라감)
```

## 아쉬운 점 / 나중에 하고 싶은 것

- DB 대신 json 파일에 저장해요. 시간이 없어서... 실제로 쓰려면 DB 붙여야 함
- 선생님 로그인이 PIN 하나라서 반별 선생님 계정이 따로 없음
- 말 점검, 위험 단어 찾기가 단어 목록 방식이라 "죽어라 공부했다" 같은 것도 걸려요. 문맥 보는 건 다음에
- 학부모용 화면도 만들고 싶었는데 못 함 (선생님 연락 가능 시간 같은 거)
- 위험 신호 오면 선생님 폰으로 푸시 알림 보내기
